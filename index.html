simulators

  • Tablet simulator

    thesevenpens.github.io/WebDrawTabSim

    An interactive 3D view of a drawing tablet and pen on a desk with a monitor. Useful for diagrams that illustrate concepts such as active area mapping, pen orientation (tilt and barrel rotation), and position tracking accuracy.

  • Lag simulator

    thesevenpens.github.io/WebDrawTabLagSim

    A live animation for exploring how different rates and latencies affect the end-to-end path of a position, from when the tablet reports it to when it appears on the display.

testers

  • Tablet Tester Basic

    thesevenpens.github.io/WebTabletTesterBasic

    A very simple web tool for quick diagnostics of drawing tablet behavior. Use it to check whether a tablet's core features are working. For deeper testing, desktop tools are recommended.

  • Tablet Tester Advanced

    thesevenpens.github.io/WebTabletTester

    An experimental tool that goes beyond basic checks of drawing tablet features to explore areas of digital art such as brush engines and stroke rendering.

  • Pressure Explorer

    thesevenpens.github.io/WebPressureExplorer

    See how pressure processing, such as curves and different smoothing algorithms, affects how pressure is handled and how it shows up in stroke rendering.

  • Drawing tablet data

    thesevenpens.github.io/DrawTabDataExplorer

    Explore public datasets for tablets, pens, and drivers, allowing you to view specs as well as performance measurements.

  • Stroke Corpus

    thesevenpens.github.io/StrokeCorpus

    A collection of carefully recorded strokes from multiple drawing tablets and pens. See every data point the tablet reported and replay the strokes, useful for analysis and for testing brush engines.

  • Open Tablet Artist

    thesevenpens.github.io/OpenTabletArtist

    WindowsA UI to make it simple to use OpenTabletDriver on Windows for artists.

  • Pixel sharpness tester

    github.com/TheSevenPens/PixelSharpnessTester

    WindowsShows test patterns on screen in a standard, consistent way, so you can judge how sharp text and other details look to the eye without apps or the operating system applying their own text rendering or anti-aliasing.

  • Pen Pressure Profiler

    github.com/TheSevenPens/PenPressureProfiler

    WindowsTool to measure a pen's pressure response. Requires a specific scale for physical force measurements.

  • Stroke Recorder

    github.com/TheSevenPens/StrokeRecorder

    WindowsRecord stroke data for later analysis and storage in StrokeCorpus.

  • WinPenKit

    github.com/TheSevenPens/WinPenKit

    WindowsLibrary to make it easy to use and switch between WinTab and Windows Ink APIs.
